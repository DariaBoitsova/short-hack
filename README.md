2) **Управление → Работа с API**
- Создайте ключ доступа с правами минимум:
  - **Сообщения сообщества**
  - (рекомендуется) **Управление сообществом**
- **Long Poll API**: включить
- Типы событий включить:
  - `message_new` (входящее сообщение)
  - `message_allow` (разрешение на сообщения)
## Яндекс.Карты на главном экране
В `public/index.html`:
- `CONFIG.YANDEX_MAP_API_KEY` — вставьте ключ JavaScript API Карт
- `X5_MAP_PLACES` — замените демо‑координаты на реальные (офисы/магазины X5)
## Запуск
Установить зависимости:
```bash
npm I
```
Запустить сервер (лендинг + API + VK‑бот):
```bash
node bot/server.js
```
Проверка:
- `http://localhost:3780` — лендинг
- `http://localhost:3780/api/health` — статус (есть ли VK/GigaChat переменные окружения)
## Переменные окружения (`.env`)
- `PORT=3780`
- `VK_GROUP_ID=...` (числовой id сообщества)
- `VK_GROUP_TOKEN=...` (ключ доступа сообщества с нужными правами)
- `GIGACHAT_AUTH_KEY=...` (Basic‑ключ для OAuth GigaChat)
