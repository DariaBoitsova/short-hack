# HR-Flow AI (X5) — лендинг + VK-бот + кабинет рекрутера

Это демо-проект “AI-рекрутинга”: кандидат заполняет анкету на лендинге, переходит в чат с VK‑ботом, проходит короткую оценку (Hard + Soft + мотивация), после чего данные попадают в кабинет рекрутёра (Топ‑20 по выбранной вакансии).

## Как работает продукт (коротко)

- **Лендинг (`public/index.html`)**
  - Кандидат выбирает направление/вакансию.
  - Заполняет “Общие данные” и **обязательно** поле “Навыки и опыт” (текст).
  - Нажимает “Начать интервью” → открывается чат `vk.com/write-{groupId}` с параметром `ref` (внутри `vacancyId` + `intentId`).

- **VK‑бот (`bot/server.js`, `bot/vk-bot.js`)**
  - Получает `ref` и сразу запускает сценарий **по выбранной вакансии**.
  - Проводит **Hard‑викторину (5 вопросов)** и **Soft‑кейс (1 открытый ответ)**.
  - Вызывает **GigaChat** для soft‑анализа (тон/вежливость/токсичность + score).
  - Вызывает **GigaChat** для “гейта навыков” (skill fit) — проверяет, есть ли в тексте навыков ключевые компетенции под вакансию.
  - Сохраняет кандидата в хранилище (`data/…`) для кабинета рекрутёра.

- **Кабинет рекрутёра (встроен в `public/index.html`)**
  - Загружает кандидатов через `GET /api/candidates`.
  - Показывает **Топ‑20 только по выбранной вакансии**.
  - Кандидаты, которые не прошли **гейт навыков**, **в топ не попадают**.

## Главная часть: как работает скоринг (алгоритм)

Скоринг строится из трёх компонент:

- **Hard Skills (0–100)**: результат викторины из 5 вопросов.
- **Soft Skills (0–100)**: оценка ответа на кейс от GigaChat (score 1–10 → умножаем на 10).
- **Motivation (0–100)**: простая эвристика (зависит от уверенного прохождения и результатов).

### Формула итогового балла

Для каждой вакансии используются **свои веса** (чтобы разные роли ранжировались справедливо).

\[
S = round(w_h \cdot H + w_s \cdot S_{soft} + w_m \cdot M)
\]

где:
- \(H\) — hard score (0–100)
- \(S_{soft}\) — soft score (0–100)
- \(M\) — мотивация (0–100)
- \(w_h, w_s, w_m\) — веса вакансии (в сумме ~ 1.0)

В коде: `bot/vk-bot.js` → `persistSession()` и функция `getWeights()` в `bot/vacancies.js`.

### “Гейт навыков”: почему кандидат может не попасть в топ

Отдельно от итогового балла есть **порог соответствия ключевым навыкам**:

- Из анкеты на лендинге берётся поле **“Навыки и опыт”** (`skillsNote`).
- Для выбранной вакансии берётся описание критичных компетенций (`getRequiredSkillsDescription(vacancyId)`).
- GigaChat возвращает JSON:
  - `fitScore` (0–100)
  - `passed` (true/false)
  - `missing` (что не хватает)

Правило:
- если **`passed=false`**, то кандидат **не участвует в топ‑20** (в кабинете рекрутёра фильтр `skillGatePassed !== false`).
- дополнительно, чтобы “неуспешные” не поднимались даже в общих списках, итоговый балл **жёстко ограничивается сверху**:
  - `weightedScore = min(weightedScore, round(35 + fitScore * 0.15))`

Это защищает от ситуации “высокий soft + мотивация” при отсутствии ключевого стека (пример: нет Python для Python‑разработчика).

### Веса по вакансиям и контент вопросов

- **Контент (вопросы/кейсы)**: `bot/vacancies.js`
  - `hard`: 5 вопросов на вакансию
  - `softCase`: 1 кейс на вакансию
- **Веса**: `bot/vacancies.js` → `getWeights(vacancyId)`
  - веса задаются на уровне вакансии/направления и применяются формулой выше

Если нужно изменить веса — меняйте их в `getWeights()` (например, для тех‑ролей увеличить hard, для розницы увеличить soft/мотивацию).

## Настройка VK

1) В сообществе VK включите:
- **Управление → Сообщения**: “Сообщения сообщества” = Включены; “Кто может писать” = Все пользователи

2) **Управление → Работа с API**
- Создайте ключ доступа с правами минимум:
  - **Сообщения сообщества**
  - (рекомендуется) **Управление сообществом**
- **Long Poll API**: включить
- Типы событий включить:
  - `message_new` (входящее сообщение)
  - `message_allow` (разрешение на сообщения)

## Яндекс.Карты на главном экране

В `public/index.html`:
- `CONFIG.YANDEX_MAP_API_KEY` — вставьте ключ JavaScript API Карт
- `X5_MAP_PLACES` — замените демо‑координаты на реальные (офисы/магазины X5)

## Запуск

Установить зависимости:

```bash
npm I
```

Запустить сервер (лендинг + API + VK‑бот):

```bash
node bot/server.js
```

Проверка:
- `http://localhost:3780` — лендинг
- `http://localhost:3780/api/health` — статус (есть ли VK/GigaChat переменные окружения)

## Переменные окружения (`.env`)

- `PORT=3780`
- `VK_GROUP_ID=...` (числовой id сообщества)
- `VK_GROUP_TOKEN=...` (ключ доступа сообщества с нужными правами)
- `GIGACHAT_AUTH_KEY=...` (Basic‑ключ для OAuth GigaChat)
